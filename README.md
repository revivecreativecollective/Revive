# Revive Homepage V1

Upload the contents of this folder to the GitHub `revive` repository.

- `index.html` — homepage
- `inquiry.html` — temporary inquiry page
- `css/style.css` — design
- `js/script.js` — interactions
- `images/` — place your photography here later

The imagery is intentionally atmospheric and temporary so your logo, icons and photography can be added later.
