# REVIVE v2 — Atmosphere Prototype

This ZIP is the first V2 structural/visual prototype based on the direction established so far.

## Current creative direction
- Digital landscape rather than a conventional business site
- Opening sky intended to feel euphoric, peaceful, entrancing and slightly impossible
- Huge photographic-feeling cloud scale, meditative motion, sunset pink/blue/orange, moon + stars
- Nature environments become the navigation language
- Voice is first-person ("I"), not "we"
- Inquiry begins as an experience, not a generic contact form

## Important
The cloud photography is NOT final in this version. The cloud layers are CSS atmospheric placeholders so the architecture and motion can be tested now. Replace them with the actual Revive cloud/sunset photography after the images are supplied.

## Files
- index.html — V2 homepage / world
- inquiry.html — first inquiry prototype
- css/style.css — visual system + responsive styling
- js/script.js — navigation + subtle parallax
- assets/clouds/ — place final cloud assets here
- assets/photos/ — place other photography here

Open index.html locally in a browser to preview.
