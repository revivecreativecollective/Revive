Update your inquiry link and portfolio without changing your website’s design.

This helper does not change the live website.

It creates a replacement content.js file. Upload that file to your GitHub revive-v3 folder along with any new photos, then redeploy the same site. Nothing here asks for a password or sends data anywhere.

Your inquiry

Edit questions in Typeform and publish your edits there. You only need to change this link if you use a different form or change its URL.

Your portfolio

For new pictures, use a path such as assets/portfolio-photos/my-photo.jpg. Upload that exact file to the same folder in GitHub. Capital letters must match.
